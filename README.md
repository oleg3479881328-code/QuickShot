# QuickShot

QuickShot is a Chrome Extension (Manifest V3) for ultra-fast area screenshots with a persistent Side Panel editor.

Primary flow:
1. Start QuickShot.
2. The Side Panel opens and area selection starts immediately.
3. Drag and select an area on the page.
4. QuickShot captures and crops the visible tab.
5. The cropped image is auto-copied to the clipboard when enabled.
6. The capture appears in the Side Panel for annotation, copying, and export.

Current launch methods:
- Left click on the extension icon.
- Keyboard shortcut `Ctrl+Shift+S`.
- Right-click context menu `Capture area with QuickShot`.
- `Capture area` button inside the Side Panel.

The Side Panel editor includes arrow, text, blur, rectangle, ellipse, crop, undo/redo, copy, PNG/JPG export, and capture settings.
